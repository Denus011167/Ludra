# Ludra — Screenshots

Screenshots of Ludra, a visual game launcher for Linux built with Python and GTK4.

**Current release:** [Ludra 1.0.0 RC3](https://github.com/Denus011167/Ludra/releases/tag/v1.0.0-rc3)

## About these screenshots

The screenshots in this directory were supplied by the project owner and show Ludra's interface during development and testing.

They illustrate aspects of the application such as its preferences, appearance customization, game-cover management and other interface features.

Some screenshots may show earlier development versions and may differ slightly from the latest release.
